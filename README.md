# 妖ノ国 Online

和風ファンタジー世界を旅するブラウザ RPG の初期プロトタイプです。既存プロトタイプはリポジトリ内に存在しなかったため、将来のオンライン化に備え、画面とゲームルールを分離して新規に構成しています。

## 現在の実装

- 行動力を使う探索、敵とのターン制戦闘、逃走、防御、LUK による会心・発見補正
- 敵ごとの経験値・文（通貨）・素材ドロップ、レベルアップ
- 武器・防具・装飾品のデータ定義、装備、鉄鉱石を使う武器強化
- HP・行動力を回復する宿、スマートフォン対応の画面
- 複数の町とサービス定義、データ駆動の職業・アクティブスキル・MP
- 踏破済みの部屋だけを保持するダンジョン進行データ、NPC Utility AI の意思決定基盤、有限の需給で更新する市場価格
- 町ごとのデータ駆動店舗での購入・売却、ブラウザ保存、競売出品／入札と賭場精算のサーバー移行可能なゲームコマンド
- 薄明の野辺の9部屋の分岐、宝箱、回復の湧き水、段階的な敵、強敵、ボス討伐報酬
- 操作ごとの自動保存と、再読込時の続きからの再開

`業` は現在、キャラクターデータとして保持しています。賭場、禁忌装備、固有イベントへ接続できるよう、単純な善悪値にはしていません。

## 開発

```bash
npm install
npm run dev
npm test
npm run build
```

`npm run dev` の表示後、通常は `http://localhost:5173/` をブラウザーで開きます。

## 構成

- `src/data/`: 調整可能なアイテム・敵データ
- `src/game/`: UI に依存しないゲーム状態とルール
- `src/main.ts`: 表示と入力イベント
- `tests/`: ルールの回帰テスト

## 次の段階

1. 町・職業・スキルと、探索地点／ダンジョンのデータ定義を追加する。
2. ダンジョンの罠・回復地点・複数階層と、町の実サービス（販売・賭場・競売所）をサーバーコマンドとして追加する。
3. ゲームコマンドと永続化をサーバー側へ移し、NPC の Utility AI と市場をサーバー時間で実行する。
